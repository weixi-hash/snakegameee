# 贪吃蛇大作战

一款基于纯前端实现的增强版贪吃蛇游戏，支持 AI 蛇对战、用户系统和历史记录功能。

## ✨ 功能特点

### 🎮 核心玩法
- **经典贪吃蛇玩法**：控制你的蛇吃食物，不断成长
- **AI 蛇对战**：游戏中存在 5 条 AI 蛇，会随机移动、吃食物，是你的竞争对手
- **双向碰撞机制**：
  - 🟢 AI 蛇头撞到你的蛇身 → 你获得大量分数并增长
  - ❌ 你的蛇头碰到 AI 蛇身体 → 游戏结束
- **食物系统**：场景中始终保持 12 个食物，吃到即增加长度和分数

### 👤 用户系统
- **注册 / 登录**：支持本地用户注册和登录
- **数据持久化**：使用浏览器 `localStorage` 存储用户数据
- **历史记录**：自动记录每局游戏的时间、分数和蛇长度

### 📱 多端支持
- **PC 端**：键盘方向键控制移动
- **移动端**：屏幕下方虚拟方向按键触摸控制

## 🚀 使用方法

### 在线体验
直接访问：[https://weixi-hash.github.io/snakegameee/](https://weixi-hash.github.io/snakegameee/)

### 本地运行
1. **克隆仓库**
```bash
git clone https://github.com/weixi-hash/snakegameee.git
```

2. **进入项目目录**
```bash
cd snakegameee
```

3. **运行项目**
   - 方式一：直接双击 `index.html` 在浏览器中打开
   - 方式二：使用本地 HTTP 服务器（推荐，部分浏览器对 `file://` 协议有限制）
   
   ```bash
   # 任选一种本地服务器工具
   python -m http.server 8000
   # 或
   npx serve .
   ```
   然后访问 `http://localhost:8000`

## 🎯 游戏操作

### PC 端（键盘）
| 按键 | 功能 |
|:----:|:----:|
| `↑` | 向上移动 |
| `↓` | 向下移动 |
| `←` | 向左移动 |
| `→` | 向右移动 |

> 按住方向键持续移动，松开停止移动。

### 移动端（触摸）
点击屏幕下方的虚拟方向按钮控制移动，松开手指即停止。

## 📖 游戏流程

1. 打开游戏首页
2. 点击「**注册**」创建账号，或直接「**登录**」已有账号
3. 登录成功后点击「**开始游戏**」
4. 使用方向键（或触摸按钮）控制蛇的移动方向
5. 吃到红色食物增加长度，同时获得 10 分
6. 引导 AI 蛇头撞到你的蛇身可获得 **大量分数**（蛇长 × 20 分）
7. 你的蛇头撞到 AI 蛇身体则 **游戏结束**
8. 游戏结束后可在「**历史记录**」中查看过往成绩

## 📊 计分规则

| 事件 | 分数 |
|:----:|:----:|
| 吃到食物 | +10 分 |
| AI 蛇头撞击你的蛇身 | AI 蛇长度 × 20 分 |

## 🛠 技术实现

| 技术 | 用途 |
|:----:|:----:|
| HTML5 Canvas | 游戏画面渲染 |
| 原生 JavaScript (ES6+) | 游戏逻辑与交互 |
| CSS3 | 界面样式与响应式布局 |
